# Codex Project Notes

## Working agreements

- Run `python -m unittest discover -s tests -p "test_*.py"` before finishing.
- Keep the project dependency-free and use only the Python standard library.
- Prefer small, readable functions over clever one-liners.

## Review guidelines

- Treat incorrect keyword ranking as a P1 issue.
- Treat missing CLI error handling as a P1 issue.
- Keep user-facing text concise and deterministic for tests.
